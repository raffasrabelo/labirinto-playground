Q-Learning

Quanto cada nova experiência altera o que o agente já sabe.
Peso das recompensas futuras. Baixo = agente “míope”.
Chance de escolher uma ação aleatória em vez da melhor conhecida.
A cada episódio, ε é multiplicado por este valor.
Cada passo custa −1 (−5 na lama).

Desenhar

Clique e arraste no labirinto para desenhar; o botão direito apaga. Arraste os quadrados azul e vermelho para mover início e objetivo.
